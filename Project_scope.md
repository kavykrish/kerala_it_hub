# Kerala IT Hub

## Project Title

Kerala IT Hub

### Subtitle

AI-Powered IT Course & Institute Navigator using Web RAG and MCP

---

## Problem Statement

Students in Kerala often struggle to find accurate and up-to-date
information about IT courses and institutes because information such
as eligibility, fees, duration, curriculum, location and admission
details is distributed across multiple websites.

---

## Proposed Solution

Kerala IT Hub is a conversational AI assistant that helps students
discover IT and technology-related courses and institutes in Kerala.

The system will retrieve relevant information from web sources,
use Retrieval-Augmented Generation (RAG) to ground the response,
and use MCP tools with an AI agent to perform retrieval tasks.
